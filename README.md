# UNA MANO EN CASA · Gestor

Versión preparada para publicar como sitio estático de GitHub Pages.

## Archivos

- `index.html`: aplicación completa, autónoma y con el logo integrado.
- `.nojekyll`: evita que GitHub Pages procese rutas de la aplicación con Jekyll.

## Activar GitHub Pages

1. Sube estos archivos a la raíz de un repositorio nuevo.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda y abre la dirección que GitHub Pages muestre.

## Datos y privacidad

La aplicación guarda y cifra los datos en el almacenamiento local del navegador con la contraseña que se crea al iniciar. No envía ni sincroniza clientes, servicios, bonos o cobros a GitHub. Cada navegador y dispositivo tendrá sus propios datos; descarga copias de seguridad desde Ajustes.

La página publicada por GitHub Pages es pública, aunque el repositorio de origen sea privado en los planes habituales. No subas copias de seguridad ni datos de clientes al repositorio.
